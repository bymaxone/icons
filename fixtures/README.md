# Test fixtures

Placeholder drawings the generator, the icon lint and the fixture package build are tested
on. They are deliberately not icons: a square, a circle with the spark dot (with filled and
16 px variants) and a triangle standing in for a brand mark. Nothing here is published, and
nothing here may be copied into `icons/`.

`fixtures/icons/` has the layout of `icons/` (see [`../icons/README.md`](../icons/README.md)),
so every command that reads the icons accepts `--icons fixtures/icons`.
